# EWS Data Tool v0.5.8

- Add custom filters for numerical tests and categories, including sites, bins, and custom labels. Use the searchable picker, drag the range handles or type bounds, and choose whether to include endpoints or invert the selection.
- Keep custom filters in the interactive workspace. Reports retain their existing filter behavior, and CSV export writes the full dataset.
- Summarize skipped CSV rows with a total and a short preview of affected line numbers.
- Show denser interactive X-axis labels on box plots and trend plots. The demo now uses OCR-style wafer IDs and includes a density slider.
- Use the Edge die wafer icon in the app header and Windows program icon.
