# EWS Data Tool v0.5.9

- Report items retain their own filters in templates. Image exports show the applied filters, and missing template references can be repaired against the current dataset.
- Scatter plots have independent X, Y and Z range settings. Specification markers can be toggled separately from the range on scatter plots and wafer maps.
- Plot statistics count dice removed by all active filters. Histogram bin controls now offer explicit Auto and Manual modes.
- Long, rotated group labels have more room in interactive box plots and trend charts. Custom label creation stays disabled until the draft is valid.

Windows x64 downloads include the installer, portable executable, combined ZIP and SHA-256 checksums.
