# Public Unix compress regression fixtures

These fixtures come from the newtua-lzw-z project's `tests/fixtures` directory:
https://github.com/new-the-unarchiver/newtua-lzw-z/tree/main/tests/fixtures

see ../../licenses/newtua-lzw-z-LICENSE-MIT.

They cover literals, repeated input, binary bytes, code-width growth to 16
bits, and 12-bit block-mode CLEAR resets. They contain no customer STDF data.
